# Peashooter look + live expressions — design

**Date:** 2026-10-10 · **Owner:** Ilan with Person 2 · **Status:** approved in brainstorming, pending spec review

## Goal

Replace the primitive-built plant with a home-made, cartoon peashooter in the tower-defence / garden-shooter style (inspired by, not copied from, PopCap/EA assets): chunky round head, short flared snout, big eyes, leaf collar, back tuft, ground leaves on a dirt mound. Opponents' heads are team-coloured (purple / yellow), the rest of the plant pea-green. The opponent's snout opens when the player's mouth opens and one eye squints when they wink.

## Decisions

| Question | Decision |
|---|---|
| Shapes | **Procedural meshes**, generated by an **editor menu builder** into mesh assets + prefab children (like `ArenaBuilder`). Shape maths are pure static functions with EditMode tests. |
| Silhouette | **B · Chunky** (mockup in `.superpowers/brainstorm/…/plant-look.html`): head radius 0.45 → **0.54 m**, stem thickness 0.14 → **0.18**, short snout with a wide flare, big eyes. |
| Hitbox | Follows the visual: head trigger sphere grows with the head (~20% larger). |
| Team colour | **Head + snout only**: host **purple** `(0.61, 0.35, 0.82)`, client **yellow** `(0.96, 0.83, 0.19)`. Stem, collar, tuft, ground leaves stay pea-green. Score bars use the same two colours. Single source: `TeamColors`. |
| Expressions | Owner syncs 2 flags (mouth open, wink) as one owner-writable byte; every copy animates snout flare + eye squint with ~0.1 s smoothing. |
| Dummies | `TargetDummy` gets the same body, keeps its own head material, neutral face (no `PlantFace` flags). |
| IP | Original geometry/materials only; no ripped game models or textures. |

## Components

### 1. `PlantMeshes` (new, `Scripts/Player/PlantMeshes.cs`, static class)

Pure mesh generators, no scene access:
- `Mesh Lathe(Vector2[] profile, int segments)` — profile points `(radius, z)`; revolves around +Z; closed ring of quads, smooth normals; open ends (caps come from separate discs).
- `Mesh Disc(float radius, int segments)` — flat disc facing +Z (mouth hole, eye pupils use spheres instead).
- `Mesh Leaf(float length, float width, float curl, int segments)` — tapered leaf along +Z, width profile `sin(πt)`, curled upward by `curl` (metres of tip lift), **double-sided** (front + back faces, flipped normals).
- Snout profile (option B), in head-local metres from the head centre: `(0.20, 0.38) → (0.17, 0.52) → (0.19, 0.62) → (0.27, 0.70) → (0.29, 0.74) → (0.25, 0.76)`; inner wall back to `(0.20, 0.70)`. Rim ends at z ≈ 0.75 = `Mouth`.

### 2. `PlantBodyBuilder` (new, `Editor/PlantBodyBuilder.cs`)

Menu **PeaHeads > Build Plant Body**. Idempotent; overwrites hand edits on generated parts (same rule as `ArenaBuilder`).

- Writes assets to `Assets/PeaHeads/Art/Plant/`: meshes `Snout.asset`, `MouthHole.asset`, `Leaf.asset`, `CollarLeaf.asset`, `TuftLeaf.asset`; materials `PlantGreen.mat`, `LeafGreen.mat`, `EyeWhite.mat`, `Pupil.mat`, `MouthDark.mat`, `Dirt.mat` (URP Lit, smoothness 0.3; `PeaHead.mat` reused for the head).
- For each of `Player.prefab` and `TargetDummy.prefab` (via `PrefabUtility.LoadPrefabContents` / `SaveAsPrefabAsset`):
  - Deletes previous children named `Gen_*`.
  - `Head`: scale **1.08** (radius 0.54; collider follows).
  - `Snout`: position 0, rotation identity, scale 1, mesh = `Snout.asset` (lathe along +Z), material = the Head renderer's current material (so tint and dummy material carry over); child `Gen_MouthHole` (disc at z 0.70, `MouthDark`).
  - `HeadPivot` children: `Gen_EyeL`, `Gen_EyeR` (white spheres Ø0.20 at (±0.17, 0.20, 0.38), each with child `Gen_Pupil` black sphere Ø0.10 pushed forward), `Gen_Collar` (5 `CollarLeaf` around y −0.45, tilted 35° down/out, `LeafGreen`), `Gen_Tuft` (2 curled `TuftLeaf` at back-top, `LeafGreen`).
  - `Visual` child `Gen_GroundLeaves` at y 0.02 with 5 `Leaf` meshes (length 0.75) radiating out, `LeafGreen`.
  - `LeafBase`: material `Dirt`, scale (0.7, 0.06, 0.7) (dirt mound; still the `StemBender`/`PlantVisuals` anchor).
  - `StemBender._thickness` = 0.18; stem source material → `PlantGreen`.
  - `PlantVisuals._groundLeaves` = `Gen_GroundLeaves` (only where a `PlantVisuals` exists — Player).
  - Player only: `PlayerCameraRig._hiddenInFirstPerson` = Head, Snout, MouthHole, both eyes + pupils, all collar + tuft leaves. `PlantFace` refs wired (§4).
- Rebuilt meshes are deterministic, so re-running produces no diff unless constants change.

### 3. `TeamColors` (new, `Scripts/Net/TeamColors.cs`, static)

- `static readonly Color Host = new(0.61f, 0.35f, 0.82f)`, `Client = new(0.96f, 0.83f, 0.19f)`, `static Color Of(int team)` (0 = host).
- `PlayerNetSync`: `_hostColor`/`_clientColor` fields removed; uses `TeamColors.Of(MatchManager.TeamOf(OwnerClientId))`. `_tinted` unchanged (Head, Snout).
- `ScoreHUD` (Person 3's file — tell them): `_team0Color`/`_team1Color` removed; uses `TeamColors.Of(team)`.

### 4. `PlantFace` (new, `Scripts/Player/PlantFace.cs`, MonoBehaviour)

Serialized: `Transform _snout`, `Transform _mouthHole`, `Transform _winkEye` (right eye), `float _openFlare = 1.22f`, `float _openHole = 1.3f`, `float _winkSquint = 0.15f`, `float _smoothing = 14f`.

- `void SetFlags(bool mouthOpen, bool wink)` — targets; `Update` eases current values with `1 − exp(−_smoothing·dt)`.
- Applies: `_snout.localScale = (flare, flare, 1)`, `_mouthHole.localScale = (hole, hole, 1)`, `_winkEye.localScale.y = rest.y · squint`. Rest scales captured in `Awake`.
- Pure: `static Vector3 Targets(bool mouthOpen, bool wink, float openFlare, float openHole, float winkSquint)` → `(flare, hole, eyeY)`; open → `(openFlare, openHole, …)`, closed → `(1, 1, …)`; wink → eyeY `winkSquint`, else 1.
- Absent refs (e.g. dummy without the component) → no-op.

### 5. Face flags over the network

- `PlayerInputFrame` gets `bool MouthOpen` (level): `locked && (mouse.leftButton.isPressed || (trackerFresh && _trackerShootPrevious))`. Zero while `Paused`/`Frozen` (existing early returns).
- `FaceFlags` (new static in `PlantFace.cs`): `static byte Pack(bool mouthOpen, bool wink)` (bit0 mouth, bit1 wink), `static (bool mouthOpen, bool wink) Unpack(byte value)`.
- `PlayerNetSync`: `NetworkVariable<byte> _face` (owner write). Owner: `_face.Value = Pack(input.MouthOpen, input.ZoomHeld)` and `face.SetFlags(...)` locally (shadows). Remote: `face.SetFlags(Unpack(_face.Value))` in `ApplyRemoteState`.

### 6. `PlantVisuals` (changed)

- Add `[SerializeField] Transform _groundLeaves`; optional. Rest scale captured in `Awake`; same `blend` as the leaf base scales it by `(plantedScale.x, 1, plantedScale.x)` (spread only, no flatten) via `LerpUnclamped`.

## Not changing

Camera rig logic, shooting/aim (Mouth stays at z 0.75), `StemBender` code, `PlantingController`, match rules, menu, tracker contract.

## Testing

- EditMode:
  - `PlantMeshesTests`: lathe vertex count = profile × (segments+1), bounds max radius = max profile radius, all normals finite + unit; leaf double-sided (front/back normals opposite), bounds length/width; disc facing +Z.
  - `PlantFaceTests`: `Targets` for the 4 flag combos; `FaceFlags` round-trip for 4 combos + bit layout.
- Builder run headless: `-executeMethod PeaHeads.EditorTools.PlantBodyBuilder.Build` with the editor closed; check prefab children exist.
- Manual (DemoArena, two machines):
  1. Prefab Mode: plant looks like mockup B; nothing floats; stem enters head; snout tip at `Mouth`.
  2. Host purple head, client yellow head on both screens; score bars match.
  3. First person: own head parts invisible, shadow visible; looking down shows stem + ground leaves, not collar.
  4. Lean: collar, eyes, tuft move with the head; stem still bends into it.
  5. Plant: ground leaves spread with the dirt mound; unplant pops back.
  6. Opponent opens mouth / holds LMB → snout flares; winks / holds RMB → right eye squints. Pause menu open → neutral.
  7. Hits on the bigger head register; pea still spawns from the snout tip.
  8. TargetDummy shows the same body with its own head material.
